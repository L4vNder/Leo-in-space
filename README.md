# Orbitwell — Crew Wellness

A playful, interactive astronaut wellness-check-in dashboard. Orbitwell gives space travelers a friendly place to log hydration, nutrition, and sleep; explore example health readings; and tick off small daily wellbeing missions.

## Run it

Open `index.html` in a modern browser. No installation, build step, or account is required. To run it from a local web server, run `python -m http.server 8000` from this folder, then visit `http://localhost:8000`.

## How to explore

- Select **Start my check-up** to work through a short, guided, four-step check-in.
- Select the **Hydration** tile or **Log a glass** to track water against the daily goal.
- Select the **Sleep quality** or **Nutrition** tile to log rest or meals.
- Complete missions in **Flight plan** to earn experience points. Your demo check-ins are saved locally in the browser.
- Select the small icon beside the Cadet profile to reset the demo; an undo option is available.

All biometric values are **illustrative demo readings**, not actual sensor measurements or medical advice. Orbitwell is not a medical device.
